Test van de git-deploy-flow

End-to-end validatie: van meta + body naar live op preview.deltainstituut.nl via een git push.

Inkoop · Onno Eric Blom · 4 mei 2026

Dit korte artikel valideert de end-to-end flow van schrijven naar live: een gegenereerd HTML-bestand, gecommit naar deltainstituut/preview-content, automatisch opgepakt door Netlify, en beschikbaar op preview.deltainstituut.nl. Geen Netlify-MCP-calls, geen handmatige uploads.

Wat wordt getest

De keten heeft drie schakels: generate.js voor de HTML, een lokale clone van preview-content voor het git-werk, en de Netlify-pipeline die op de gepushte commit reageert.

  • Skill-detectie van slug en dossierkleur
  • Validatie van de 11-punts delivery-checklist
  • Push naar main zonder conflicten
  • Netlify-deploy binnen ~30 seconden zichtbaar

Hoe het werkt

Niets meer dan dit:

  1. Schrijf meta.json en body.md
  2. Run generate.js
  3. Kopieer de output naar ~/preview-content/artikelen/<slug>/index.html
  4. git commit && git push

De Netlify-pipeline heeft geen build-stap — het is een statische site, dus de deploy is alleen het uploaden van veranderde files. Daardoor blijft de TTL (push tot live) onder een halve minuut.

Wat na deze test gebeurt

Als alles werkt: dit artikel wordt direct daarna verwijderd via een tweede commit. De cleanup is zelf ook een test van de revert-route.

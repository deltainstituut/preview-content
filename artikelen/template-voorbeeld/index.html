Referentie-pagina voor de delta-html-documents skill

NADI · Onno Eric Blom · 10 mei 2026

Deze pagina demonstreert elke visuele component van de delta-html-documents skill. Gebruik hem als referentie wanneer je een nieuw Delta Instituut document schrijft. De eerste alinea is automatisch een <p class="lead"> — 1.18rem, twee zinnen, vat de kern samen.

Lead, paragrafen en links (H2)

Een gewone paragraaf gebruikt de standaard Lora-typografie op 1.05rem met line-height 1.7. Inline-links zoals rijksfinancien.nl krijgen de dossierkleur via a.inline-link. Inline code met enkele backticks rendert als <code> met monospace.

Tussen alinea's komt automatisch verticale ruimte. Een tweede paragraaf landt direct hieronder met margin-top: 0 zodat de spacing strak blijft.

Subkop H3 (H3)

Een h3-niveau is bedoeld voor onderdelen binnen een h2-sectie. Ze verschijnen niet in de TOC (auto-derived uit h2's), maar wel in de visuele hiërarchie van het artikel.

KPI-rij (H2)

Voor kerncijfers bovenaan een sectie gebruik je <div class="kpi-row"> met losse <div class="kpi"> cards. Auto-fit grid, minimaal 180px per card.

Callout (H2)

Voor terzijdes of waarschuwingen — linkerborder in dossierkleur, transparante achtergrond.

Let op

Deze callout staat voor een korte, opvallende mededeling die niet in de hoofdlijn van de tekst hoort. Eerste alinea zonder margin-top, laatste zonder margin-bottom.

Figuur met caption (H2)

Voor PNG/JPG-grafieken inline. Assets moeten naast index.html in de deploy-directory staan; <img src> blijft relatief.

Tabel (H2)



Tabellen zijn standaard markdown met | … |. Op desktop normaal, op mobiel automatisch gestapelde kaarten met data-label per cel.

Lijsten (H2)



Markdown ongeordende lijst:



  • Eerste item met ::marker in dossierkleur
  • Tweede item, line-height 1.55 voor leesbaarheid
  • Derde item kan ook nested sublijsten bevatten:
    • Sub-item één
    • Sub-item twee



Genummerde lijst werkt identiek met 1. syntax.



TOC en navigatie (H2)



In de linker zijbalk staat het label *INHOUDSOPGAVE* (Johnston / Hammersmith One), gevolgd door een progress-track. Het actieve item krijgt een 2px verticale bar in de dossierkleur naast de tekst, zodat je in één oogopslag ziet waar je bent.



Op mobiel (<1024px) klapt de zijbalk weg en verschijnt bovenaan een sticky drawer met dezelfde Johnston-typografie. Klik om in/uit te klappen.



Verboden (H2)



  • Geen bold/italic markdown markers — de minimal parser laat ze als literal ** staan
  • Geen blauwe strepen boven secties
  • Geen progress bar bovenaan scherm op desktop
  • Geen externe <link> of <script src> (uitzondering: /fonts.css); @import binnen inline <style> is wel OK
  • Geen bronnenlijst onderaan — gebruik sidenote-kolom (<sup class="fn-ref"> + meta.sidenotes)
